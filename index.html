What we rejected — and exactly why.

The board only shows pools that pass. This page shows the ones that failed. Every refusal is counted — and published — and the most severe classes get a named receipt with the precise reason, up to 100 per snapshot. A system that can't hide the shape of its failures is a system you can actually trust. It's a receipt, not a promise.

The public ledger.

Every ~5 minutes the agent commits a full snapshot of the market to git — a public, versioned history where each snapshot is a timestamped commit the agent only ever appends to. Tamper-evident, not tamper-proof: its value is that everything is public, versioned, and anyone can replay any moment — including the raw numbers behind every figure on this site. Click any snapshot below to replay exactly what the wire saw at that moment; we fetch it live from the git history.

Where the AI fits — and doesn't.

Facts: deterministic rulesVerification: on-chain + source dataExplanation: optional AI

The agent gathers, filters, detects, and verifies with deterministic rules — the same input always produces the same output. An optional LLM may write at most one summary sentence, only about already-verified facts, and a claim-checker rejects any sentence that invents a number. The AI never decides whether a number is true. Keyless mode (no model at all) is fully supported, and the site shows which mode produced each snapshot.

Privacy & safety

  • Read-only, always. The agent calls public Base RPC endpoints (getReserves, getBlockByNumber). No wallet, no keys, no funds, no transactions. Ever.
  • This page sends nothing. No web3 libraries, no connect buttons, no forms. It reads two public JSON files from the repo and public APIs. You can verify this yourself — the whole site is one HTML file in a public repo.
  • No personal data. Nothing about you is stored, anywhere. The Telegram alerts you opt into carry only market data.
  • The numbers are checkable. Every verified pool links to the exact contract and block on BaseScan. If we're wrong, it's public.

The stack ($0/month)

  • GitHub Actions — runs a monitoring cycle every 5 minutes. Public repos get free compute, and each ~6-hour job hands off to the next one automatically, so the cadence never depends on one job surviving.
  • GitHub Pages — this site, and the public, versioned data history
  • Public Base RPC + DeFiLlama + CoinGecko — the senses. One yield index, one on-chain reader, one price source. No paid API anywhere.
