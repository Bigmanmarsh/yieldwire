How a number is made

deterministic end to end
1
FETCH

DeFiLlama /yields — every 5 minutes, on GitHub Actions. One free, keyless, public source. Its name is on every receipt.

2
NORMALIZE

Base · stablecoin · TVL ≥ $500K. Stale, outlier (APY > 500%) and dead pools are rejected — and the rejection count is published, not hidden.

3
SOURCE INTEGRITY

Wherever all three APY components exist, apy = apyBase + apyReward must hold (±0.5pp). The pass rate is shown under the board.

4
DETECT

Four published thresholds, plain arithmetic, 12h per-pool cooldown. No model is involved in this step — or any step that produces a number.

5
DELIVER

Telegram alert + public receipt. The LLM (optional) writes exactly one summary sentence; any number it invents gets the sentence rejected by the claim-checker. Rejections are counted and published.
